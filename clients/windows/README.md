# Yumeiro Windows 客户端（Electron 原生桌面客户端）

> **状态：0.7.0。** 聊天、市场、智能体、工作区、设置和管理入口在本地客户端界面中渲染，不再把这些功能页作为服务器网页嵌入。工作区采用 IDE 布局：文件树、文本编辑器、运行输出和协作面板分栏显示；编译器（Claude Code / Codex / Pi）与模型、权限独立选择。普通聊天只显示普通模型或智能体，收起侧栏后工作区主区会铺满窗口。

## 0.46.1（版本号现在和服务端统一）

- **壁纸只存在这台电脑上**：在“设置 → 壁纸”里选本机图片、内置渐变或服务器壁纸库里的图，选择和遮罩深浅只保存在本机；不再读取、也不再修改服务器账号里的壁纸偏好，更不会跟着服务器的默认壁纸变。
- **管理页**：管理员可以在客户端里管理服务器端设置——成员、安全与熔断、套餐与授权（目前全部功能向所有人开放）、模型价格、站点设置和智能体引擎。这些都是服务器上的设置，改动对所有人生效。

## 它做什么
- 独立窗口，加载你自己服务器上的 Yumeiro 网页（聊天、图片、语音、工作区、远程控制都和浏览器里一样）。
- 单实例、系统菜单（聊天 / 工作区 / 远程控制 / 更换服务器）、外部链接用系统浏览器打开。
- 只允许导航到你的服务器；只放行麦克风、剪贴板、全屏权限。
- 首次启动输入服务器地址（保存在 `%APPDATA%\Yumeiro\config.json`），也可用环境变量 `YUMEIRO_URL` 指定。

## 自己构建
需要 Node.js 18+，能访问 GitHub（下载 Electron，约 115 MB）：
```bat
cd clients\windows
npm install
npm start            :: 直接运行看效果
npm run build        :: 在 dist\ 生成安装版和免安装版
```
图标在 `build/icon.ico`（由站点图标生成）。正式分发建议购买代码签名证书，并在 `package.json` 的 `build.win` 里配置。

## 和“被控端”的区别
本客户端是**你用来操作 Yumeiro 的窗口**。想让这台电脑被手机远程控制，另外运行被控端代理 `agent.mjs`（见《客户端与远程控制说明.md》）。

## 桌宠
客户端启动后会在屏幕右下角出现透明置顶的桌宠「梦色」：拖动、双击打开主窗口、右键菜单；托盘图标可开关桌宠和开机自启。代码在 `pet.html`、`pet-preload.js` 和 `pet/`（由 `node scripts/sync-clients.mjs` 从 `public/pet.js` 同步）。桌宠开着时，关闭主窗口只会收到托盘。

桌宠有情绪（喜 / 怒 / 哀 / 乐）：回答完成会开心、出错会难过、被连续戳会生气、被夸会大笑；情绪数值随时间回落，右键菜单可看当前心情并「哄哄她」。网页版额外支持「AI 台词」开关（让聊天模型按情绪现编一句，消耗额度，默认关）。
