Yumeiro 首次安装

分步骤完成服务器、存储、模型和客户端初始化。安装令牌只用于保护首次安装入口，正常打开链接即可自动带入。

管理员账号

这是登录 Yumeiro 管理后台的本地账号。

安装组件

只执行已勾选的固定安装步骤，不接受任意命令或软件包。

服务器组件

服务器与存储

选择 PostgreSQL 后，向导会先测试连接，再在服务重启时执行 JSON → PostgreSQL 自动迁移。

模型服务

选择服务商并填写 API Key，向导会从服务商自动获取可用模型。API Key 只写入服务器秘密文件。

选择模型后，安装时会把该模型 ID 写入服务器配置。

Cindy 桌面端与客户端

这两项分别代表下载包发布和服务器上的 Cindy 桌面容器。Windows 沙箱只模拟容器安装。

Cindy 官方账号绑定不会在这里收集密码。完成本地管理员登录后，可继续使用现有“绑定 Cindy 账号”流程。
