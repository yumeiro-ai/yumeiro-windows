# Yumeiro 安卓原生客户端

Kotlin + Jetpack Compose 写的真原生界面（不是网页外壳）：

- 登录（服务器地址、邮箱、密码；自签名证书可勾“忽略证书错误”；没写 http/https 时先试 https，不行自动改 http）
- 对话列表按“今天/昨天/最近 7 天/更早”分组，重命名、删除、复制整段对话
- 流式回复 + Markdown（标题、列表、引用、代码块可复制）
- 选择模型、默认模型
- 附件：图片与文件（PDF/Word/Excel/文本等由服务器解析），上传进度与取消，点开查看
- 设置：账号与用量、修改密码、默认模型、记忆（开关/查看/添加/删除/清空）、外观（深色/浅色/跟随系统、壁纸、字体大小）、退出登录
- 智能体：新建/编辑/删除，选模型、绑定技能、选择用于新对话
- 技能：新建/编辑/删除；技能市场：浏览、预览、一键安装
- 网页找回密码确认（仅管理员）：网页登录页“忘记密码 → 手机确认”会显示 6 位验证码，在手机上输入（或直接点列表里自动出现的请求）批准/拒绝
- 手机联动（1.4.0）：扫一扫（确认电脑扫码登录、打开“发到手机”的对话/工作区）、传文件到电脑（工作区的“手机上传”文件夹）、远程操控电脑（看画面、点按、输入文字）、任务完成通知（前台服务长轮询，设置里开关）
- 管理（仅管理员，0.46.1 扩充）：成员（添加、停用、重置密码、删除）、全员用量、MCP 服务开关、安全与熔断（敏感内容拦截、机密工作区允许名单、公司邮箱域名限制、熔断与费用上限、实时熔断状态与手动暂停/恢复、告警记录）、套餐与授权（只读：目前全部功能向所有人开放，各版本仅作介绍，“即将开放购买”不可点，不能切换也不能输入授权码）、模型价格（按模型选货币和输入/输出单价、汇率、从服务商读取）、站点设置（名称、登录页公告、使用模式）；添加/编辑 MCP、模型服务商、自定义正则等仍在网页版。这些设置影响所有成员，服务端同样只允许管理员
- 壁纸（0.46.1 起只在本机）：壁纸和遮罩只保存在这台手机上，不跟服务器、账号走，换服务器或换账号不变；默认无壁纸，不再使用服务器的默认壁纸，也不再读写服务器上的壁纸偏好。可从手机相册选图（校验确实是图片，最大 20 MB、最多 1 亿像素，缩小到 1920 像素内以 JPEG 存进应用私有目录，不需要存储权限），也可选服务器壁纸库里的图（只在本机记住文件名；被删掉后悄悄回到无壁纸），或内置渐变。旧版本从服务器同步下来的壁纸选择不会迁移

模型服务商、MCP 编辑等管理后台仍在网页版。

构建：运行 `build-apk.bat`（或 `gradlew.bat assembleDebug`），产物在 `app/build/outputs/apk/debug/app-debug.apk`。
旧的网页外壳版仍在 `../android`（Capacitor），不再作为发布的 APK。
